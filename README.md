# Employee-Management-System

A desktop-based Employee Management System developed using Java and MySQL.  
This project helps manage employee records such as adding, updating, searching, and deleting employee details efficiently.

---

## 🚀 Features

- Add new employees
- Update employee information
- Delete employee records
- Search employee details
- View all employees
- MySQL database connectivity
- User-friendly interface
- Fast and efficient data management

---

## 🛠️ Technologies Used

- Java
- Java Swing / AWT
- MySQL
- JDBC
- VS Code
